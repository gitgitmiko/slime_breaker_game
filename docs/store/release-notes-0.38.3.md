# Catatan rilis 0.38.3 (versionCode 54)

Untuk Play Console. Tempel blok ini di kolom catatan rilis (batas 500 karakter per bahasa). Menggantikan 0.38.2 (tidak diunggah); mencakup semua perubahan iklan sejak 0.38.1.

```
<id-ID>
Perbaikan iklan:
- Lanjutkan setelah nyawa habis kini wajib menonton iklan. Kalau iklan diblokir (AdGuard dll.) atau tidak ada koneksi, muncul pesan dan run tidak bisa dilanjutkan.
- Iklan saat power-up dan sebelum lantai boss kini hanya dari jaringan iklan; tidak ada lagi iklan pengganti dari game.
</id-ID>
<en-US>
Ad fixes:
- Continue after losing every life now requires watching an ad. If ads are blocked (AdGuard etc.) or you are offline, a message appears and the run cannot continue.
- Ads at power-ups and before boss floors now come only from the ad network; the game's own stand-in ad is gone.
</en-US>
```
